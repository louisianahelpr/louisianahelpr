# Poster CPP — screenshots

Drop the **Poster-funnel** screenshots into this folder, sized for each
required display class. Fastlane uploads from these subdirectories automatically
when the `release_poster_cpp` lane runs.

## Required sizes

| Device              | Folder                | Pixel size  |
|---------------------|-----------------------|-------------|
| iPhone 6.7" / 6.9"  | `iphone_6_7/`         | 1290 × 2796 |
| iPhone 6.1"         | `iphone_6_1/`         | 1179 × 2556 |
| iPad 12.9" (6th)    | `ipad_pro_12_9/`      | 2048 × 2732 |

## Recommended frame order (1–5)

1. **Post a Job in 60s** — the PostJob form mid-fill, budget visible
2. **Choose Your Helpr** — applicant list with ratings + parish badges
3. **Secure Escrow Payment** — the Stripe checkout step with "held until complete"
4. **Real-time Chat & Photo Proof** — Messages screen with a before/after pair
5. **Tap to Approve** — JobConfirmation screen with the green "Mark Complete" CTA

Each screenshot should have a Louisiana-friendly caption overlay
(matching the same font and brand color used on louisianahelpr.com).
