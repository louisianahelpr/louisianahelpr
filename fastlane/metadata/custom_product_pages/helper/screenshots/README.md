# Helper CPP — screenshots

Drop the **Helper-funnel** screenshots into this folder, sized for each
required display class. Fastlane uploads from these subdirectories automatically
when the `release_helper_cpp` lane runs.

## Required sizes

| Device              | Folder                | Pixel size  |
|---------------------|-----------------------|-------------|
| iPhone 6.7" / 6.9"  | `iphone_6_7/`         | 1290 × 2796 |
| iPhone 6.1"         | `iphone_6_1/`         | 1179 × 2556 |
| iPad 12.9" (6th)    | `ipad_pro_12_9/`      | 2048 × 2732 |

## Recommended frame order (1–5)

1. **Available Jobs Near You** — Dashboard with the open jobs list filtered by parish
2. **Apply in One Tap** — JobDetailDialog with the "Apply" button highlighted
3. **Track Your Earnings** — EarningsTab showing weekly totals and pending payouts
4. **Same-Day Payouts** — InstantPayoutDialog mid-flow
5. **Build Your Reputation** — UserProfile with parish badges + 5-star reviews

Each screenshot should have a Louisiana-friendly caption overlay
(matching the same font and brand color used on louisianahelpr.com).
