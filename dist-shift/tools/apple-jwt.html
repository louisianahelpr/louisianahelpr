Apple Sign In JWT Generator

Builds the OAuth client_secret JWT that Supabase requires for the Apple provider.

This tool runs entirely in your browser. Your private key never leaves this page — no server, no network calls, no logging. Uses the Web Crypto API (built into every modern browser) to sign the JWT locally.
