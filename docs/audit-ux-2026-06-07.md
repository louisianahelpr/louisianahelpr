### False positives — verified NOT bugs

- **`usePostJobForm.ts:103-118` "dropped platform-fee error → revenue loss."** The RPC error *is* surfaced via `report(error, { severity: "error", … })`; `platformFee` is display-only (the authoritative fee is computed server-side at checkout). No change needed.
- **`Jobs.tsx:145-154` "`console.log` ships to production."** The log is gated behind `DEBUG_AUTH = import.meta.env.DEV`; it no-ops in the production bundle. No change needed.
- **Route existence sweep.** All 23 rendered routes + 16 `<Navigate>` redirects resolve to real lazy imports; `AdminHelperTiers` was the only broken `Link`/`navigate` target found.
- **`DOCUMENT_SCROLL_ROUTES` vs shell choice.** No mismatches — every page's wrapper agrees with its entry in `useAppShellViewport.ts`.
- **Secrets / prod URLs / debug flags.** Clean. `capacitor.config.ts` only injects a `server` block behind `CAP_DEV_URL` (dev hot-reload only); production loads bundled `dist/`. `Info.plist` has all required usage strings + `aps-environment`.

## Phase 2 — UI/UX & responsiveness (grouped by screen)

Targets: iPhone SE (320–375w, ~550px usable height) and Pro Max. Most issues are SE-class crowding and missing micro-interactions.

### Auth & onboarding
- 🎨 `CompleteProfile.tsx:360-409` — eyebrow + 8-item checklist + 9-field form stack tall on SE with no marked scroll container; reads cramped. Consider a collapsible/below-the-fold checklist on small heights.
- 🎨 `AccountPending.tsx:279` — `max-w-[28ch]` on dynamic copy can wrap jaggedly on SE with a long first name. Consider `max-w-none` on the smallest breakpoint.
- 🎨 `SignupStep2.tsx` — visual parity gap: business Step 1 has an icon/banner treatment the personal path lacks; typography between steps is slightly inconsistent.

### Dashboard / jobs / activity
- 🎨 `JobHistory` metadata row is cramped on SE.
- 🎨 Applicants modal has no `max-w` on iPad → over-wide.
- 🎨 "Clear filters" is a weak affordance; easy to miss.
- 🎨 Missing haptics on job-card taps (a Capacitor Haptics call would match the native feel used elsewhere).

### Post-job
- 🎨 Stepper crowds on SE small-height; checkbox tap target is under the comfortable 44px.
- 🎨 No scroll-to-first-error on validation failure — the user can submit and not see which field failed above the fold.
- 🎨 Image grid reflow is tight; numeric keyboard has no "Done" accessory.

### Messages
- 🎨 Outbound bubble `rgba(0,0,0,0.18)` on parchment text can read low-contrast on OLED dark; inbound can read gray-on-gray.
- 🎨 No "jump to newest" affordance when scrolled up while new messages arrive.
- 🎨 Load-older scroll restoration is fragile when the keyboard opens/closes mid-load (safe-area inset shifts).
- 🎨 `PayoutCelebration` confetti (14 particles / 2.4s) may stutter on SE under load.

### Profile / settings
- 🎨 Typography scale drifts across tabs (eyebrow/title sizes not uniform).
- 🎨 iPhone SE: sort-label truncation in Saved Helprs toolbar.
- 🎨 Safe-area padding inconsistency — `ProfileLanding` uses a computed `pb`, `ScheduleTab` hardcodes `pb-10`.
- 🎨 Portfolio gallery lacks scroll-snap; pull-to-refresh only on the landing tab.
- 🎨 Missing haptics on destructive actions (e.g. remove saved helpr).
- 🔍 `NotificationPreferences` mounts without a Suspense fallback at `Profile.tsx:~721` — verify it can't flash empty.

### Landing / legal / shell
- 🎨 `HeroSection.tsx:366-381` — "Coming soon to Google Play" badge advertises a not-yet-shipped Android app. Intentional and styled correctly; flagging only as a **product call** for the iOS App Store listing.
- ✅ `NotFound`, `Legal` (per-tab canonical URLs + native AppShell to dodge the iOS fixed-header momentum-scroll bug) are well-handled — no action.
