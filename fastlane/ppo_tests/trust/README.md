# Trust vs. Value — visual direction

## Hypothesis
Does **safety messaging** (control) beat **price messaging** (treatment)
on App Store install conversion among first-time visitors in Louisiana?

## Control screenshot story (1–5)
1. Hero card: shield + "ID-verified helprs" caption
2. Stripe escrow checkout step with "held until you approve"
3. Photo proof gallery (before/after on a real job)
4. 5-star review wall
5. Parish badge map of coverage

## Treatment screenshot story (1–5)
1. Hero card: "$50" price tag + "most jobs under $50" caption
2. Job feed with budget chips highlighted
3. "Booked in 4 minutes" timestamp ribbon
4. Saved-helpr quick-rebook flow
5. Calendar showing same-day availability

Use the same brand color and font on both arms — only the *message* should
differ. Keep the screenshot count and order identical so Apple's PPO engine
isolates the message variable cleanly.
