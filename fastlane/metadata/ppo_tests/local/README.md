# Broad vs. Hyper-Local — visual direction

## Hypothesis
Does **statewide broad copy** (control) beat **parish-specific copy**
(treatment) on install conversion when targeting Iberia + Vermilion users?

This is the test most likely to inform a *fleet* of CPPs — if hyper-local
wins, we'll spin up one CPP per parish (Apple now allows 70 total).

## Control screenshot story (1–5)
1. Hero: Louisiana state outline filled with helpr avatars
2. Statewide categories grid (lawn / cleaning / handyman / errands)
3. Generic Louisiana skyline behind dashboard screenshot
4. National-style review wall — names blurred, ratings sharp
5. "Coverage statewide" coverage map

## Treatment screenshot story (1–5)
1. Hero: Iberia + Vermilion parish outlines, with two pinned helpr avatars
2. "12 helprs in Erath this week" stat panel
3. Photo of New Iberia downtown, helpr at work in foreground
4. Local landmark backdrop (Avery Island salt dome, sugar mill skyline)
5. Local-only review wall — first names + parish, e.g. "Marie, Vermilion"

Run the treatment **only** for users whose iOS region is set to LA, OR
target the campaign at Iberia/Vermilion zip codes via paid social so the
geo claim stays honest.
